# Legal-Width Joint GA Design

## Scope

Replace the production GA structure chromosome from per-atomic-unit binary
decisions to one legal retained-width index per existing local pruning domain.
The domain definition, dependency closure, physical pruning replay, canonical
precision groups, strongly typed explicit-QDQ deployment, and Stage-2 objective
remain unchanged.

The migration is in-place. The existing runner continues to own search and
deployment. Legacy masks remain readable through an explicit import adapter,
but new populations, crossover, mutation, cache identity, and reports use legal
width genes.

## Ownership Boundaries

1. `search/space/legal_width_inventory.py` enumerates legal retained widths
   before GA starts. It consumes current atomic units and physical constraints;
   it does not alter the tracer or dependency graph.
2. `search/decoding/fixed_taylor_width_decoder.py` owns the immutable mapping
   from a width vector to pruned atomic units. It uses one canonical prune-only
   Taylor ranking generated from the original unquantized model.
3. `search/encoding/legal_width_genotype.py` and `search/operators/` own typed
   chromosomes, stable hashes, initialization, domain crossover, and legal
   neighbor mutation.
4. The existing `CandidatePhenotype` remains the contract consumed by joint
   Taylor scoring, physical replay, QDQ, TensorRT, and Stage-2.
5. `search/archive/feasible_pareto_archive.py` retains unique feasible
   phenotypes across runs and budgets. `search/reporting/pareto_frontier.py`
   produces official fronts only from full-validation AP and isolated real
   engine latency.

## Genotype And Deterministic Decode

The formal genotype is `C=(s,b)`, where `s[d]` is an index into the sorted
legal widths `K_d` and `b[q]` is a deployable precision action. A genotype may
carry legacy `group_mask` only when explicitly marked as imported; it cannot be
generated by the formal GA.

For domain `d`, the decoder resolves `k_d=K_d[s[d]]` and prunes the lowest
`N_d-k_d` units in the persisted prune-only ranking. Dense domains use one
ranking. Grouped convolutions use one ranking per physical group and retain the
same count in every group without requiring shared relative channel positions.
The decoded masks are nested over legal widths.

`M=M(s)`: precision is absent from the decoder API and cache key. Consequently,
precision-only mutation or crossover cannot change pruned units, channel masks,
the physical plan, or the structure hash.

## Ranking And Candidate Score

The canonical structure ranking is computed once from original weights,
mean task gradients, and the empirical Fisher diagonal:

`I_prune_2(u) = sum(|g_i w_i|) + 0.5 * sum(h_i w_i^2)`.

Overlapping dependency slices are counted once per physical parameter element.
The ranking manifest is bound to checkpoint, model config, Fisher manifest,
inventory, code, and tie-break policy hashes. First-order ranking is retained
only for anchor ablation.

The full candidate still uses the already implemented joint perturbation:

`delta W = M(s) * Q_b(W) - W`.

`L_joint = sum(|g_i delta w_i|) + 0.5 * sum(h_i delta w_i^2)` and
`J1 = 0.8 * exp(-L_joint/tau) + 0.2 * (1-R_param)`.

SQNR stays diagnostic. BOPS is a hard feasibility constraint, not part of J1.
The fixed tau artifact remains read-only during every generation.

## Genetic Operations And Repair

Structure mutation moves one selected domain by one adjacent legal width index,
with an optional budget-aware choice of domain. Structure crossover selects a
whole domain gene from either parent. Precision mutation and crossover operate
only on complete canonical precision groups.

New candidates are legal by construction and never invoke repair. Repair is an
exception path for legacy/external/corrupt inputs. It may only restore channels,
may not add requested pruning, and may not change precision. Conditional Taylor
may be used inside that exception path or a separately enabled post-search
fixed-width channel-swap experiment; it is disabled in the formal decoder.

## Hash And Lineage Contract

Each candidate records independent hashes for genotype, width vector,
structure, precision, phenotype, and physical plan. The phenotype hash is the
hash of `(structure_hash, precision_hash)`. Physical export verifies that its
mask and parameter count exactly match the decoded plan; it cannot rerank or
repair.

## Search And Real Evaluation

The main search uses the current accepted 4090 production BOPS target
`0.21 +/- 0.005`; the older generic config does not define a hard 0.4 target.
Three independent seeds each run at least 64 population for 30 generations.
Anchor-derived, safe existing, adjacent-width, precision-solved, mixed, and a
small number of random legal-width seeds initialize the population.

An external archive retains non-dominated feasible candidates across task
score, BOPS, physical parameter retention, and latency proxy. If the main band
does not cover enough resource levels, at least four additional reachable BOPS
bands are derived from real anchors. Stage-2 uses ranked backfill from at least
15 archived candidates, runs real physical pruning, typed ONNX, explicit QDQ,
calibration, strongly typed TensorRT, fixed 50-frame evaluation, and full
validation for non-dominated/band representatives.

All formal latency points are replayed serially on one idle RTX 4090 after
builders and evaluation workers stop. Official Pareto fronts use only full-val
mAP and this isolated real latency; screening AP and proxy latency cannot enter
them.

## Fail-Closed Rules

Missing domain/ranking/precision mappings, illegal width indices, non-nested
masks, nonfinite joint scores, precision fallback, decoded/replayed mask
mismatch, predicted/physical parameter mismatch, BOPS failure, evaluation
skips, mixed validation protocols, or concurrent formal latency workers exclude
the candidate and preserve a failure record. Deployment-unavailable INT8 is
removed from the action set rather than represented as nominal INT8.

## Verification

Implementation follows RED-GREEN tests for legal inventory, 10,000 random
legal chromosomes, deterministic/nested decode, grouped independence,
structure/precision orthogonality, exception-only repair, scalar/batched joint
score parity, physical replay identity, archive deduplication, and Pareto data
protocol isolation. Experiment outputs are timestamped and ignored by Git;
only code, tests, lightweight summaries, plots, configs, and reports are
committed.
